工作流程

WORKFLOW

维护源文件→

在 NAS 上通过 iptv-manager 等工具维护直播源，导出文件到固定目录（文件名可随时变化）。

自动检测→

定时任务自动选取最新源文件，20 并发逐条探测有效性，失效源剔除，组播源保留。

自动推送→

匹配台标与节目信息后生成订阅文件，推送到 GitHub 并刷新 CDN，全程无人值守。

订阅分发→

播放器导入订阅地址即可观看；多人订阅按用户独立生成，到期自动失效。

安装方法

INSTALL

1准备环境

飞牛 NAS（支持 SSH 终端）、GitHub 账号 + 推送令牌。
  • NAS：飞牛 OS，开启 SSH，终端可执行 python3
  • GitHub 令牌：Settings → Developer settings → Personal access tokens，勾选 repo 权限生成
  • 源目录：直播源导出目录，如 /vol1/1000/docker/iptv-manager/data/uploads

2下载部署包

部署包包含全部脚本与配置模板，支持下载到任意 NAS（飞牛 / 群晖 / 威联通等）部署。包内不含任何私有信息，可放心下载。
下载部署包china-iptv-sources-nas.tar.gz · 6MB

3部署到 NAS

把部署包放到 NAS 上，解压到项目目录，写入 GitHub 推送令牌。
# 解压部署包到项目目录
tar -xzf china-iptv-sources-nas.tar.gz -C /vol1/1000/docker/china-iptv-sources/

# 写入 GitHub 推送令牌（必填）
echo -n "github_pat_你的令牌" > .github_token

# 确认关键文件就位
ls -la push_nas.py gen_token.py config.json

4配置定时任务（crontab -e，每天七轮自动检测并推送）

每天 5:00 / 8:00 / 11:00 / 14:00 / 17:00 / 20:00 / 24:00 自动运行七轮：更新源文件 → 检测有效性 → 立即推送 GitHub 并同步台标/节目单。源文件名变化也不影响，脚本自动取最新文件。
# 每天 5/8/11/14/17/20/24 点 —— 更新源 + 检测有效性 + 立即推送（共 7 轮）
0 0,5,8,11,14,17,20 * * * cd /vol1/1000/docker/china-iptv-sources && python3 push_nas.py --latest-dir /vol1/1000/docker/iptv-manager/data/uploads --validate --sync-epg --sync-logo >> push_run.log 2>&1

5多人订阅管理（每人独立地址，到期自动失效）

每次推送时自动为未过期用户生成专属订阅文件并推到 GitHub；到期的用户文件自动删除，播放器打不开。用户清单保存在 NAS 本地 users.json，不随仓库发布。
# 新增用户（到期日期 YYYY-MM-DD，输出专属订阅地址）
python3 gen_token.py --add 张三 --expire 2027-01-01

# 查看所有用户与订阅地址（已过期的会标注）
python3 gen_token.py --list

# 续期（重新执行 --add 即可，旧地址自动失效）
python3 gen_token.py --add 张三 --expire 2027-06-01

# 删除用户（下次推送后订阅自动失效）
python3 gen_token.py --remove 张三

6手动运行验证

首次部署建议手动跑一轮完整流程，确认日志无报错后即可交给定时任务。
# 完整跑一轮（检测+同步+推送）
nohup python3 -u push_nas.py --latest-dir /vol1/1000/docker/iptv-manager/data/uploads --validate --sync-epg --sync-logo > push_run.log 2>&1 &

# 实时查看进度
tail -f push_run.log
第一次全量检测约需 30–60 分钟（2 万条源、20 并发、每条超时 4 秒）。检测完成后日志会打印推送结果与各用户订阅地址。

7使用说明

订阅文件为标准格式，导入任意支持 M3U / TXT 的播放器即可使用。
  • 电脑：VLC「打开网络串流」/ PotPlayer「打开 URL」，粘贴订阅地址
  • 手机 / 电视：TiviMate、影视仓、小薇直播等，添加订阅地址
  • TVBox：使用 TXT 格式订阅地址（live.txt）
  • 多人分享：把各用户的专属地址分别发给对应的人，到期自动失效
  • 更新频率：订阅文件每天两轮自动更新，播放器重新打开即可获取最新列表
M3U 头部自动挂载双 EPG 节目单，每条频道带台标（tvg-logo）与节目标识（tvg-id），播放器支持即可显示台标和当日节目信息。
